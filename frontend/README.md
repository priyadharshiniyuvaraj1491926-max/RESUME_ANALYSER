# ResumeIQ AI — Frontend

React 18 + Vite single-page application for ResumeIQ AI.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Default: `VITE_API_BASE_URL=http://localhost:8001/api`
3. Start development server:
   ```bash
   npm run dev
   ```
   App runs at `http://localhost:5173`.
4. Build for production:
   ```bash
   npm run build
   ```
